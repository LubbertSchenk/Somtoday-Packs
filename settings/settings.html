Privacy

Grade history is stored in Chrome storage on this device. The extension does not send grades, credentials, or page contents to an external server owned by Lubbert Schenk. It reads visible Somtoday content only on matching Somtoday pages.

Compatibility

Somtoday markup can change. The detector prioritizes semantic/data-test/class clues and visible text, with a conservative fallback. A changed markup may require selector updates. No private Somtoday API is used. When Somtoday updates their UI, this extension may not work until it is updated. If you notice a problem, please report it on the GitHub issue tracker.
