How to install the extension?

Well, this is a great question. Since we don't have it published on the Chrome Web Store, you need to manually upload it following the steps below.

Important Note

Please put the downloaded folder you got from the GitHub Repository in your Documents folder of Windows / macOS / Linux. You cannot delete the folder because it is required to load the Grade Packs and update your saved grades (which are saved locally inside the folder).

1
Chrome Extensions

The first step is to go to chrome://extensions in your Chrome browser. This can be achieved by typing it in the top search bar.

An alternative way to go there is by clicking the three dots in the top right corner, then Extensions, and then Manage extensions.

2
Developer Mode

The second step is to enable Developer Mode. You can do this by clicking the slider in the top right corner where 'Developer mode' is gray. By clicking this, you will see three more buttons appear in the top left corner.

3
Uploading the Extension

The third step is to upload the folder (which you unzipped and put somewhere safe like the Documents folder). This can be done by pressing the Load unpacked button in the top left corner. Then a file window will open, where you will need to select the folder named Somtoday-Packs.

Please note: Your file explorer may look different because this image was taken on macOS. This does not change any compatibility.

After you have uploaded the extension, you will see that the extension will be visible right next to any other installed extensions, and in the top right corner you will see the extension logo.

4
Testing

Now you can go to https://leerling.somtoday.nl and log in with your credentials. After that, go to the grades page (/cijfers) where you will see that you can open new packs.

If this is not the case, don't worry! This happens sometimes because the extension loads all already registered grades to the save file—this is completely normal. If you do want to test if it is working, go to the Somtoday Packs extension and press the small logo next to the extensions button (found next to the three dots in the top right corner).

Then, click the Reset grade history button and you will see that you have new packs to open. If that does not work, you can try via the Settings page by clicking the Open settings button in the same pop-up.

Here you can press the Mark all current grades as new (Cus why not?) button to reset all data stored and then open the packs (again).
